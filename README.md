# Kurumbar Public Website (`www.kurumbar.org`)

Next.js App Router + TypeScript + Tailwind CSS public portal for Home, About Us, Member Registration, Gallery, Contact, and Public Member ID QR Verification (`/verify/:memberId`) in English and Tamil.

## Setup

```bash
cp .env.template .env.local
pnpm install
pnpm run dev
```

## Scripts

- `pnpm run dev` — Start Next.js dev server
- `pnpm run build` — Build production bundle
- `pnpm run lint` — Run ESLint
